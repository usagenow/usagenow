# UsageNow 0.7.1

AI coding usage tracker for macOS. Usage, limits, reset times, and activity across Codex, Claude Code, Gemini CLI, Antigravity, Kiro, Warp, OpenCode, Qoder, Qwen Code, Cline, and Grok Build — plus DeepSeek, Kimi, OpenRouter, and Ollama Cloud — from the menu bar.

## New

- **Choose UsageNow's language** in Settings › General › Language: follow macOS, or pick German, English, Spanish, French, or Russian, then Restart Now. The widget follows too.
- **Rename an added account** from its … menu in Settings › Providers.

## Improved

- An added account's actions share one menu, so its row fits in every language.
- An empty or missing account folder says so, instead of asking you to sign in.
- Report a Problem includes the language UsageNow is set to.

## Fixed

- Adding an account made the other added accounts read their month of sessions again.

## Install

Already on 0.4.0 or later? UsageNow offers this update itself — or choose **Check Now** in Settings › General.

Otherwise, download `UsageNow-0.7.1.dmg` below and drag UsageNow to Applications.

Requires macOS 15 or later. Signed with a Developer ID and notarized by Apple.
