# UsageNow 0.4.0

AI coding usage tracker for macOS. Usage, limits, reset times, and token activity across Codex, Claude Code, Gemini CLI, and Antigravity, from the menu bar.

## New

- **What today's tokens would cost** — an estimate beside each provider's totals, at published API prices. Cached tokens are priced as cached, which is most of the volume in Claude Code. A sense of scale, not a bill: a subscription doesn't charge per token.
- **Updates in the app** — UsageNow checks for and installs its own updates, and only ones carrying its signature. The switch is in Settings › General. A check sends nothing about you.

## Changed

- Refresh draws an arc of progress around the arrow instead of spinning the icon in place.
- The menu bar percentage is sized to the icons beside it.

## Install

Download `UsageNow-0.4.0.dmg` below and drag UsageNow to Applications.

Coming from 0.3.0 or earlier, install this one by hand — those versions have no updater. From here on, updates arrive in the app.

Requires macOS 15 or later. Signed with a Developer ID and notarized by Apple.
