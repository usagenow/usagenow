# UsageNow 0.5.0

AI coding usage tracker for macOS. Usage, limits, reset times, and activity across Codex, Claude Code, Gemini CLI, Antigravity, Kiro, and Warp — plus DeepSeek, Kimi, and OpenRouter balances — from the menu bar.

## New

- **Kiro** — your plan's monthly credit limit, when it resets, and today's credits and prompts. Read from what Kiro writes on your Mac; no request to Kiro, no Kiro credential.
- **Warp** — today's agent requests, credits, and tokens per model, from Warp's local database, read-only. Prompt text is never read.
- **DeepSeek, Kimi, and OpenRouter** — balances and spending from their official APIs, with your own API key. The key stays in your Keychain, goes only to that provider, and is deleted when you turn the provider off. None of the three is verified against a live account yet.

## Install

Already on 0.4.0? UsageNow offers this update itself — or choose **Check Now** in Settings › General.

Otherwise, download `UsageNow-0.5.0.dmg` below and drag UsageNow to Applications. Coming from 0.3.0 or earlier, install it by hand once.

Requires macOS 15 or later. Signed with a Developer ID and notarized by Apple.
