# Changelog (Korean)

What's New in Korean: each version's changes, shorter than CHANGELOG.md. Headings stay in English; the app translates them. A version missing here shows in English.

## 0.9.0

### Added

- **JetBrains AI(실험적).** JetBrains IDE에 저장된 AI Assistant 한도와 보고된 충전 시각을 메뉴 막대와 위젯에 표시합니다. 오래된 데이터는 원래 기록 시각을 유지합니다. 인증 정보 접근이나 네트워크 요청은 없습니다. 활성 AI Assistant를 통한 실제 검증은 아직 필요합니다.
- **개인별 위젯.** 위젯마다 제공업체와 계정을 선택하거나 비워 두어 UsageNow 설정을 따를 수 있습니다. 이름을 바꿔도 선택은 유지되며 삭제된 계정이 다른 계정으로 자동 교체되지 않습니다.
- **큰 위젯.** 최대 네 개의 제공업체·계정 행에 두 개의 한도 기간과 초기화 시간을 표시합니다. 정제된 스냅샷만 렌더링합니다.
- **한도 사용 속도.** 가장 임박한 한도에 대해 15분 이상에 걸친 최신 측정 세 건 이상으로 로컬 차트와 추정치를 표시합니다. 캐시 반복, 오래된 값, 긴 공백, 초기화, 알 수 없는 기간은 예측에 쓰지 않습니다. 토큰 수로 계산하지 않습니다.
- **선택적 서비스 장애 표시.** OpenAI, Claude, Cursor, GitHub Copilot의 공개 상태 페이지를 확인합니다. 기본값은 꺼짐이며 10분간 캐시합니다. 계정 연결·한도와 별개이고 계정·사용량 데이터를 보내지 않습니다.
- **네덜란드어(Nederlands).** 앱, 위젯, 내장 변경 기록을 포함해 이제 열 개 언어를 지원합니다.
- **Windsurf와 ElevenLabs 아이콘 개선.** 밝은 화면과 어두운 화면에 맞는 올바른 로고를 사용합니다.

- **IDE 없이 Antigravity 사용.** IDE가 응답하지 않으면 호환되는 CLI 1.x(1.1.11 이상)의 공식 `agy /usage` 보고서를 읽습니다. 에이전트를 실행하지 않고 UsageNow가 인증 정보에 접근하지 않으며, 5분간 캐시합니다. CLI 1.2.2에서 확인했습니다.

## 0.8.0

### Added

- 키, 토큰, 쿠키는 저장 전에 읽기 전용 사용량 요청으로 확인합니다. 인증 정보, 권한, 네트워크, 키체인 문제를 구분하여 안내합니다. 취소하면 기존 연결은 변경되지 않습니다.
- HTTP 429가 발생하면 서비스가 지정한 시각까지 연결 새로고침을 일시 중지합니다. 수동 새로고침도 대기 시간을 따르며 다른 계정은 계속 작동합니다. 기존 데이터의 원래 확인 시각은 유지됩니다.
- Cursor, GitHub Copilot, Perplexity, ElevenLabs, Z.ai를 추가했습니다. 설정에서 직접 연결하며 기본적으로 꺼져 있습니다. Cursor와 Perplexity는 별도의 임시 로그인 창 또는 수동 쿠키 입력을 지원하고, Copilot은 본인의 GitHub 토큰을 사용합니다. ElevenLabs는 공식 API를, 나머지 네 연동은 실험적 API를 사용합니다. 실제 계정에서는 아직 검증하지 않았습니다.
- 계정 크레딧과 문자 수는 오늘의 활동과 별도로 표시합니다. 무제한 또는 알 수 없는 할당량을 임의의 비율로 표시하지 않습니다.
- Windsurf: 로컬 캐시에서 일간·주간 한도, 재설정 시간, 요금제를 표시합니다. 이전 요금제는 결제 주기의 크레딧을 표시합니다. 인증 정보를 읽거나 네트워크 요청을 보내지 않습니다. 최신 버전에 로그인한 환경에서는 아직 검증하지 않았습니다.
- 포르투갈어, 일본어, 한국어, 히브리어를 추가하여 총 9개 언어를 지원합니다. 위젯은 오른쪽에서 왼쪽으로 읽는 레이아웃도 지원합니다.
- 새로운 기능 안내를 모든 지원 언어로 번역했으며 오프라인에서도 볼 수 있습니다.
- “Codex · 업무”처럼 추가한 계정을 메뉴 막대에 표시할 수 있습니다. 계정을 삭제하면 제공자의 기본 계정으로 돌아갑니다.

### Fixed

- 위젯은 제공자별 데이터 수집 시간을 보관합니다. Codex를 갱신해도 오래된 Claude 한도가 최신으로 보이지 않으며, 오래된 데이터에는 시계가 표시됩니다.
- 한도가 재설정되면 새 데이터를 받을 때까지 이전 사용률은 알 수 없음으로 표시됩니다. 카운트다운은 위젯 갱신 사이에도 계속 진행됩니다.
- 사용률이 바뀌지 않아도 새로 읽은 시간을 저장합니다.

### Development

- Debug 빌드는 별도 식별자와 데이터 컨테이너를 사용하여 설치된 위젯에 영향을 주지 않습니다. 자동 업데이트는 꺼져 있으며 테스트는 실제 제공자를 시작하지 않습니다.

- Qoder — 오늘 사용한 크레딧과 그 크레딧으로 받은 응답. Qoder가 Mac에 기록하는 대화 기록에서 읽습니다. Qoder의 로그인 정보는 열지 않습니다.

- 오래된 Claude 한도에 업데이트 방법이 표시되어, 한 시간 전 비율을 현재 값으로 착각하지 않습니다.
- 위젯이 UsageNow를 열라고 요청하는 대신, 더 새로운 버전의 앱 데이터를 읽습니다.
