# Changelog (Japanese)

What's New in Japanese: each version's changes, shorter than CHANGELOG.md. Headings stay in English; the app translates them. A version missing here shows in English.

## 1.0.0

### Added

- アプリとウィジェットにカザフ語、ウズベク語、トルコ語を追加し、13言語に対応。ウズベク語ではÖ、Ğ、Ş、Çを使用します。
- プロバイダーを選ぶ任意の初期設定を追加。スキップでき、設定から再度開けます。既存の設定は維持され、初回のデータ取得は初期設定の完了またはスキップ後に始まります。
- プロバイダー別の通知しきい値、独立したリセット通知、Macの時間帯に従う通知休止時間を追加。スキップした通知は後送りせず、古い値では警告しません。
- 任意のCLI：usagenow statusとusagenow status --jsonで安全なスナップショットと更新時刻を確認。プロバイダー通信、認証、履歴出力は行いません。設定 › 一般からインストールできます。
- スリープ解除後の更新、通知設定の移行、スナップショット互換性を検証。CLIではリセット後の割合を不明とし、非対応の形式を拒否します。

## 0.9.0

### Added

- **JetBrains AI（実験的）。** JetBrains IDEのAI Assistantが記録した利用上限と補充日時を、メニューバーとウィジェットに表示します。古いデータは元の記録日時を保持します。認証情報へのアクセスやネットワーク通信はありません。有効なAI Assistantでの実機検証は未完了です。
- **個別のウィジェット設定。** ウィジェットごとにプロバイダーとアカウントを選択できます。未選択ならUsageNowの設定に従います。名前を変更しても選択は保持され、削除したアカウントが別のものに置き換わることはありません。
- **大きなウィジェット。** 最大4つのプロバイダー・アカウントを、2つの上限期間とリセット時刻付きで表示します。安全なスナップショットだけを描画します。
- **上限の消費ペース。** 最も厳しい上限について、15分以上にわたる3回以上の新しい測定からローカルグラフと推定を表示します。キャッシュの重複、古いデータ、長い中断、リセット、期間不明の場合は予測しません。トークン数からは計算しません。
- **任意のサービス障害表示。** OpenAI、Claude、Cursor、GitHub Copilotの公開ステータスを確認します。初期状態はオフで、10分間キャッシュします。接続や上限とは別の情報で、アカウントや使用量は送信しません。
- **オランダ語（Nederlands）。** アプリ、ウィジェット、同梱の更新履歴に対応し、10言語になりました。
- **WindsurfとElevenLabsのアイコンを更新。** ライト・ダーク表示に対応した正しいロゴを使用します。

- **IDE なしの Antigravity。** IDE が応答しない場合、互換性のある CLI 1.x（1.1.11 以降）の公式 `agy /usage` レポートを読み取ります。エージェントは実行せず、UsageNow は認証情報にアクセスしません。5 分間キャッシュし、CLI 1.2.2 で確認済みです。

## 0.8.0

### Added

- キー、トークン、Cookieは保存前に読み取り専用の使用量リクエストで確認します。認証情報、権限、ネットワーク、キーチェーンの問題を区別して表示します。キャンセルしても以前の接続は変更しません。
- HTTP 429ではサービスが指定した時刻まで接続の更新を一時停止します。手動更新でも待機時間を守り、他のアカウントは更新を続けます。以前のデータは元の読み取り日時を保持します。
- Cursor、GitHub Copilot、Perplexity、ElevenLabs、Z.aiに対応。設定から明示的に接続し、初期状態はオフです。CursorとPerplexityは一時的な専用ウインドウでサインインするか、Cookieを手動入力できます。Copilotはご自身のGitHubトークンを使用します。ElevenLabsは公式API、残り4つは実験的な連携です。実際のアカウントでは未検証です。
- アカウントのクレジットと文字数は、今日のアクティビティとは別に表示します。無制限や不明の利用枠から割合を推測しません。
- Windsurf：ローカルキャッシュから1日・週間の制限、リセット時刻、プランを表示します。旧プランでは請求期間のクレジットを表示します。認証情報の読み取りやネットワーク通信は行いません。最新版にログインした環境での動作は未確認です。
- ポルトガル語、日本語、韓国語、ヘブライ語を追加し、9言語に対応しました。ウィジェットは右から左への表示にも対応します。
- 「新機能」をすべての対応言語に翻訳し、オフラインでも読めるようにしました。
- 「Codex · 仕事」など、追加したアカウントをメニューバーに表示できます。削除すると、そのプロバイダーの最初のアカウントに戻ります。

### Fixed

- ウィジェットはプロバイダーごとにデータの取得時刻を保持します。Codexの更新によって古いClaudeの制限が新しく見えることはなく、古いデータには時計が表示されます。
- リセット後の使用率は、新しいデータを取得するまで不明になります。カウントダウンはウィジェットの更新の間も進みます。
- 使用率が変わらなくても、再取得した日時を保存します。

### Development

- Debugビルドは専用の識別子とデータコンテナを使い、インストール済みのウィジェットに干渉しません。自動更新は無効で、テストは実際のプロバイダーを起動しません。

## 0.7.0

### Added

- 複数のアカウント：Codex または Claude Code の2つ目のフォルダ、あるいは DeepSeek、Kimi、OpenRouter、Ollama Cloud の別のAPIキー。それぞれが「Codex · 仕事」のように、好きな名前で独自のセクションを持ちます。UsageNowがアカウント自体の名前やメールアドレスを読み取ることはありません。
- Qwen Code — 今日のトークン、リクエスト、モデルと、その推定コスト。Qwen CodeがMacに書き込むセッションの記録から読み取ります。
- Cline — 今日のトークン、APIリクエスト、モデルと、Clineが記録したコスト。エディタ内のClineのタスクとCline CLIから読み取ります。プロンプト、応答、キーは読み取りません。
- Grok Build — 今日のトークン、モデル呼び出し、モデルと、xAIが報告したコスト。Grok Buildのセッションログから読み取ります。
- ウィジェットに直近2週間：制限のないプロバイダ向けに、アクティビティの推移だけを表示します。数値は表示しません。
- UsageNowがドイツ語、スペイン語、フランス語、ロシア語に対応。Macの言語に従います。
- 設定 › 情報に「新機能」：各バージョンの変更点をアプリ内で確認できます。

### Changed

- ClineとGrok Buildでは、推定ではなくツール自体が記録したコストを表示します。

## 0.6.1

### Added

- 制限の通知：制限の残りが20%、さらに5%になったときにそれぞれ1回、また通知を受けた制限がリセットされたときに通知します。デフォルトはオフで、設定 › 通知でオンにできます。
- どのアプリからでもUsageNowを開ける独自のキーボードショートカット。設定 › メニューバーで記録します。追加のアクセス権は不要です。

### Changed

- コストの推定がClaude Sonnet 5.5とGPT-6.1に対応しました。

### Fixed

- 更新中に「再試行」を押したり、APIキーを追加したり、プロバイダをオンにしたりすると、無視されることがありました。
- UsageNowが言語サーバを探している間、Antigravityがほかのプロバイダを待たせることがなくなりました。
- セッションファイル内の非常に長い行は、メモリに読み込まずにスキップするようになりました。

## 0.6.0

### Added

- 各プロバイダの下に過去30日間：1日ごとのバー、その月のトークン合計、推定コスト、最もよく使ったモデル。バーにポインタを置くとその日が表示されます。グラフは設定 › 一般でオフにできます。
- OpenCode — 今日のトークン、リクエスト、モデルとそのコスト。OpenCodeのローカルデータベースから読み取り専用で読み取ります。プロンプトと応答は読み取りません。
- Qoder — 今日使ったクレジットと、それで支払われた応答。QoderがMacに書き込むトランスクリプトから読み取ります。Qoderのサインイン情報は開きません。
- Ollama Cloud（試験的）— セッションと週間の制限。ご自身のCloud APIキーを使います。
- 制限を残りまたは使用済みで表示 — ウインドウ、メニューバー、ウィジェットで。
- Kiro、Warp、Qoderのクレジットをウィジェットに表示。
- 設定 › 情報に「問題を報告」：まずレポート全体を表示し、その後ご自身でGitHubのIssueまたはメールとして送信します。名前、パス、キー、プロンプトは含まれません。

### Changed

- メニューバーのウインドウの透明度を下げ、小さな画面でははみ出さずにスクロールするようになりました。
- 設定 › プロバイダがノートパソコンの画面に収まるようになりました。
- コストの推定が、Claude Opus 5.5やGPT-6を含む最新のモデルに対応しました。
- 1か月分のセッションファイルの読み込みが数倍速くなり、メモリの使用量も大幅に減りました。

### Fixed

- ChatGPT 26.9で内蔵のCodex CLIの場所が変わってから、Codexの制限が更新されなくなっていました。
- 古くなったClaudeの制限に更新方法が表示されるようになり、1時間前の割合を現在の値と取り違えることがなくなりました。
- ウィジェットが、UsageNowを開くよう求める代わりに、新しいバージョンのアプリのデータを読み取るようになりました。
- Codex app-serverが早く終了しすぎると、UsageNowが何も表示せずに終了することがありました。

## 0.5.0

### Added

- Kiro — プランの月間クレジット上限、リセット日、今日のクレジットとプロンプト。KiroがMacに書き込む内容から読み取ります。Kiroへのリクエストも、Kiroの認証情報も使いません。
- Warp — 今日のエージェントのリクエスト、クレジット、モデル別のトークン。Warpのローカルデータベースから読み取り専用で読み取ります。
- DeepSeek、Kimi、OpenRouter — 公式APIからの残高と支出。ご自身のAPIキーを使います。キーはキーチェーンに保管され、そのプロバイダにだけ送信されます。3つとも、実際のアカウントではまだ検証されていません。

## 0.4.0

### Added

- 今日のトークンの推定コスト：各プロバイダの合計の横に、公開されているAPI価格での推定額を表示します。キャッシュされたトークンはキャッシュ価格で計算します。目安であり請求額ではありません。サブスクリプションはトークン単位で課金されません。
- アプリ内アップデート。UsageNowが自分でアップデートを確認してインストールします。UsageNowの署名があるものだけです。確認の際にあなたに関する情報は送信されません。0.3.0からは、一度だけ0.4.0を手動でインストールしてください。

### Changed

- 更新中はアイコンを回転させる代わりに、矢印の周りに進行状況の弧を描くようになりました。
- メニューバーの割合の大きさを、隣のアイコンに合わせました。

## 0.3.0

### Added

- Antigravity — モデルグループごとの5時間と週間の制限、そしてプラン。Antigravityアプリの実行中に、そのアプリから読み取ります。認証情報は使わず、127.0.0.1より先には接続しません。
- Gemini CLI — ローカルのセッションの記録からトークン、リクエスト、モデルを読み取ります。制限は報告されないため表示しません。
- モデル別のアクティビティ：Codex、Claude Code、Gemini CLIの「今日のモデル」の一覧。最も活発なモデルが先頭です。
- Teamプラン：ClaudeはTeam · Premiumのようにシートを、CodexはTeam、Business、Enterpriseを表示します。
- AntigravityとGemini CLIのメニューバーのモード。
- 設定でプロバイダをドラッグして並べ替えられます。ウインドウとウィジェットもその順序に従います。
- CursorとGitHub Copilotを「近日対応」として掲載。

### Changed

- プロバイダが3つ以上ある場合、中サイズのウィジェットはプロバイダごとに1行、小サイズは制限に最も近い最大3つを表示します。
- アップデートで追加されたプロバイダは、一度だけ自動でオンになります。オフにしたものはオフのままです。

### Fixed

- Claudeの制限でログインパスワードを求められなくなり、Claude Codeを起動すると自動で復帰するようになりました。
- 留守の間にリセットされたClaudeの制限期間も表示されたままになり、使い切った制限はサインインなしで表示されます。
- 最後に確認したClaudeの制限が、アプリの終了やアップデート後も保持されるようになりました。

## 0.2.0

### Added

- 実データ：Codexの制限、リセット時刻、プランを公式のCodex app-serverから。CodexとClaude Codeのトークン、リクエスト、最後に使ったモデルをローカルのセッションファイルから。
- デスクトップのウィジェット（小と中）。
- Claude Codeの制限 — 試験的で、デフォルトはオフ。
- CodexとClaude Codeを個別にオン・オフできます。
- メニューバーのモード：アイコンのみ、最も上限に近い制限、または1つのプロバイダ。
- ライト、ダーク、システムの外観。

### Changed

- 使用量を残りで表示し（「残り58%」）、使うにつれてバーが短くなります。
- 制限の期間はプロバイダが報告するとおりに表示し、足りないものを作り出すことはありません。
- 制限を読み取れない場合、最後に確認した値を「古い」と明示し、理由を1行添えて1日間表示します。
