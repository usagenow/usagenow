# UsageNow 0.7.0

AI coding usage tracker for macOS. Usage, limits, reset times, and activity across Codex, Claude Code, Gemini CLI, Antigravity, Kiro, Warp, OpenCode, Qoder, Qwen Code, Cline, and Grok Build — plus DeepSeek, Kimi, OpenRouter, and Ollama Cloud — from the menu bar.

## New

- **More than one account.** Add a second Codex or Claude Code folder, or another API key for DeepSeek, Kimi, OpenRouter, or Ollama Cloud, in Settings › Providers. Each account gets its own section, widget row, and notifications — "Codex · Work" — under a name you choose. UsageNow never reads an account's own name or email.
- **Qwen Code, Cline, and Grok Build.** Today's tokens, requests, and models, and the 30-day history, from the files each tool writes on your Mac. Cline and Grok Build record what each request cost, and that's the figure you see. Qwen Code and Grok Build aren't yet verified against live installs.
- **The last two weeks in the widget** for providers without limits — the shape of your activity, never amounts.
- **German, Spanish, French, and Russian.** UsageNow follows your Mac's language.
- **What's New** in Settings › About: every version's changes, inside the app.

## Install

Already on 0.4.0 or later? UsageNow offers this update itself — or choose **Check Now** in Settings › General.

Otherwise, download `UsageNow-0.7.0.dmg` below and drag UsageNow to Applications.
