# Changelog (Russian)

What's New in Russian: each version's changes, shorter than CHANGELOG.md. Headings stay in English; the app translates them. A version missing here shows in English.

## 1.1.0

### Added

- Обзор — Сегодня / 7 дней / 30 дней. Локальная активность на этом Mac. История может быть неполной.
- Наборы аккаунтов — Наборы меняют отображение. Включённые аккаунты продолжают обновляться и отправлять уведомления.
- Отдельные иконки провайдеров — Показывайте иконки выбранных провайдеров и их лимиты рядом в строке меню.
- Адаптивно — Обновление учитывает каждый аккаунт, доступность сети, режим питания и блокировку экрана. Серверные паузы соблюдаются всегда.
- Баланс и бюджеты — Предупреждения при 80% и 100% бюджета по сообщённому расходу. Только предупреждения. Бюджеты не блокируют расход. Периоды — по часовому поясу провайдера; оценки по API-ценам не учитываются.
- MiniMax — Следите за лимитами MiniMax M Plan.

## 1.0.0

### Added

- Казахский, узбекский и турецкий в приложении и виджетах — всего тринадцать языков. В узбекском переводе используются Ö, Ğ, Ş и Ç.
- Необязательная настройка первого запуска с выбором провайдеров. Её можно пропустить и открыть из настроек. Обновление сохраняет прежние настройки; новый запуск чтения данных начинается после завершения или пропуска настройки.
- Пороги уведомлений для каждого провайдера, отдельные оповещения о сбросе и тихие часы по часовому поясу Mac. Пропущенные уведомления не накапливаются; старые лимиты не вызывают предупреждений.
- CLI по желанию: usagenow status и usagenow status --json читают безопасный snapshot с отметкой свежести. Без запросов к провайдерам, авторизации и экспорта истории. Установка через Настройки › Основные.
- Обновление после сна, проверка миграции уведомлений и совместимости snapshot. CLI убирает процент после сброса, сохраняет неизвестные значения и отклоняет неподдерживаемый формат.

## 0.9.0

### Added

- **JetBrains AI (экспериментально).** Локальные лимиты AI Assistant из IDE JetBrains и указанная IDE дата пополнения — в menu bar и виджетах. Старые значения сохраняют исходное время замера. Без чтения учётных данных и сетевых запросов. Проверка с активным AI Assistant ещё предстоит.
- **Персональные виджеты.** Выбирайте провайдеров и аккаунты отдельно для каждого виджета или оставьте выбор пустым, чтобы следовать UsageNow. Переименование сохраняет выбор; удалённый аккаунт не заменяется другим.
- **Большой виджет.** До четырёх подробных строк провайдеров и аккаунтов с двумя окнами квот и временем сброса. Виджет по-прежнему читает только безопасный снимок данных.
- **Темп расхода квоты.** Локальный график и явно обозначенная оценка для наиболее критичного окна по минимум трём свежим замерам за 15 минут. Повторы из кеша, устаревшие данные, долгие перерывы, сбросы и неизвестная длина окна исключают прогноз. Токены для расчёта не используются.
- **Опциональные статусы сервисов.** Публичные страницы OpenAI, Claude, Cursor и GitHub Copilot; по умолчанию выключено, кеш — десять минут. Статусы отделены от подключения аккаунта и лимитов; данные аккаунта и использования не отправляются.
- **Нидерландский (Nederlands).** Приложение, виджеты и встроенный список изменений — теперь десять языков.
- **Обновлённые иконки Windsurf и ElevenLabs.** Корректные логотипы для светлой и тёмной темы.

- **Antigravity без IDE.** Если IDE не отвечает, UsageNow читает официальный отчёт `agy /usage` из совместимых CLI 1.x начиная с 1.1.11. Без запуска агента и чтения учётных данных со стороны UsageNow; кэш — пять минут. Проверено с CLI 1.2.2.

## 0.8.0

### Added

- Ключи, токены и cookie проверяются запросом на чтение статистики до сохранения. Понятные сообщения о неверных данных, правах доступа, сети и Связке ключей; отмена не меняет прежнее подключение.
- При ограничении частоты запросов (HTTP 429) подключение делает паузу до указанного сервисом времени. Ручное обновление не обходит паузу; другие аккаунты продолжают работать, старые данные сохраняют исходную дату.
- Cursor, GitHub Copilot, Perplexity, ElevenLabs и Z.ai: явное подключение в настройках, по умолчанию выключены. Вход Cursor и Perplexity — в отдельном временном окне или через cookie вручную; Copilot — со своим GitHub-токеном. ElevenLabs использует официальный API, остальные четыре интеграции — экспериментальные. На реальных аккаунтах пока не проверены.
- Кредиты и символы аккаунта показаны отдельно от активности за сегодня. Безлимитные и неизвестные квоты не превращаются в выдуманные проценты.
- Windsurf: дневные и недельные лимиты, время сброса и тариф из локального кеша; для старых тарифов — кредиты за расчётный период. Данные входа не читаются, сетевых запросов нет. С актуальной авторизованной установкой пока не проверено.
- Португальский, японский, корейский и иврит — теперь девять языков. Виджет поддерживает отображение справа налево.
- «Что нового» переведено на все языки приложения и работает офлайн.
- В строке меню можно выбрать добавленный аккаунт, например «Codex · Работа». После его удаления показывается основной аккаунт провайдера.

### Fixed

- Виджет хранит время получения данных каждого провайдера: свежие данные Codex не скрывают устаревшие лимиты Claude. Старые данные отмечены часами.
- После сброса лимита старый процент становится неизвестным до получения новых данных. Обратный отсчёт продолжает идти между обновлениями виджета.
- Новое чтение лимитов сохраняет актуальную дату, даже если процент не изменился.

### Development

- У Debug-сборок отдельные идентификаторы и контейнер данных, чтобы не мешать установленному виджету. Автообновления выключены; тесты не запускают реальные провайдеры.

## 0.7.0

### Added

- Больше одного аккаунта: вторая папка Codex или Claude Code или ещё один ключ API для DeepSeek, Kimi, OpenRouter или Ollama Cloud — у каждого свой раздел, «Codex · Работа», под именем, которое вы зададите. Имя и email самого аккаунта UsageNow не читает.
- Qwen Code — токены, запросы и модели за сегодня и во что они обошлись бы, из записей сессий, которые Qwen Code пишет на вашем Mac.
- Cline — токены, запросы к API и модели за сегодня со стоимостью, которую записал Cline, из задач Cline в редакторе и из Cline CLI. Промпты, ответы и ключи не читаются.
- Grok Build — токены, вызовы модели и модели за сегодня со стоимостью, которую сообщил xAI, из журналов сессий Grok Build.
- Последние две недели в виджете — для провайдеров без лимитов: форма вашей активности, без самих чисел.
- UsageNow на немецком, испанском, французском и русском — по языку вашего Mac.
- «Что нового» в Настройки › О программе: изменения каждой версии прямо в приложении.

### Changed

- Для Cline и Grok Build показывается стоимость, которую записал сам инструмент, а не оценка.

## 0.6.1

### Added

- Уведомления о лимитах: когда остаётся 20% и ещё раз 5% — по одному разу, — и когда лимит, о котором вас предупредили, обновился. По умолчанию выключены; включаются в Настройки › Уведомления.
- Своё сочетание клавиш, чтобы открыть UsageNow из любого приложения. Запишите его в Настройки › Строка меню. Дополнительных разрешений не нужно.

### Changed

- Оценка стоимости знает Claude Sonnet 5.5 и GPT-6.1.

### Fixed

- «Повторить», только что добавленный ключ API или только что включённый провайдер могли игнорироваться, если нажать их во время обновления.
- Antigravity больше не задерживает других провайдеров, пока UsageNow ищет его языковой сервер.
- Очень длинная строка в файле сессии пропускается, не загружаясь в память.

## 0.6.0

### Added

- Последние 30 дней под каждым провайдером: столбик на каждый день, итог месяца по токенам, примерная стоимость и самая используемая модель. Наведите на столбик, чтобы увидеть день. Графики выключаются в Настройки › Основные.
- OpenCode — токены, запросы и модели за сегодня и их стоимость, из локальной базы OpenCode, только для чтения. Промпты и ответы никогда не читаются.
- Qoder — кредиты, потраченные сегодня, и ответы, за которые они заплачены, из расшифровок, которые Qoder пишет на вашем Mac. Вход в Qoder никогда не открывается.
- Ollama Cloud (экспериментально) — лимиты на сессию и неделю, с вашим ключом Cloud API.
- Лимиты как остаток или расход — в окне, строке меню и виджете.
- Кредиты в виджете для Kiro, Warp и Qoder.
- «Сообщить о проблеме» в Настройки › О программе: сначала весь отчёт, потом вы сами отправляете его как issue на GitHub или письмо. Никаких имён, путей, ключей и промптов.

### Changed

- Окно в строке меню менее прозрачное и прокручивается, а не уходит за край маленького экрана.
- Настройки › Провайдеры помещаются на экран ноутбука.
- Оценка стоимости знает новейшие модели, включая Claude Opus 5.5 и GPT-6.
- Чтение файлов сессий за месяц в разы быстрее и требует гораздо меньше памяти.

### Fixed

- Лимиты Codex перестали обновляться с ChatGPT 26.9, который перенёс встроенный Codex CLI.
- Устаревшие лимиты Claude теперь подсказывают, как их обновить, чтобы часовой давности процент не принимали за текущий.
- Виджет читает данные более новой версии приложения, а не просит открыть UsageNow.
- UsageNow мог молча закрыться, если Codex app-server завершался слишком рано.

## 0.5.0

### Added

- Kiro — месячный лимит кредитов плана, дата сброса и кредиты и промпты за сегодня, из того, что Kiro пишет на вашем Mac. Никаких запросов к Kiro и учётных данных Kiro.
- Warp — сегодняшние запросы агента, кредиты и токены по моделям, из локальной базы Warp, только для чтения.
- DeepSeek, Kimi и OpenRouter — балансы и траты из их официальных API, с вашим ключом API. Ключ остаётся в Связке ключей и отправляется только этому провайдеру. Ни один из трёх пока не проверен на живом аккаунте.

## 0.4.0

### Added

- Во что обошлись бы сегодняшние токены: оценка рядом с итогами каждого провайдера по опубликованным ценам API, кэшированные токены — по цене кэша. Ориентир, а не счёт: подписка не берёт плату за токены.
- Обновления внутри приложения. UsageNow сам проверяет и ставит обновления, причём только со своей подписью. Проверка ничего о вас не сообщает. С 0.3.0 один раз установите 0.4.0 вручную.

### Changed

- Обновление рисует дугу прогресса вокруг стрелки, а не крутит значок.
- Процент в строке меню подогнан по размеру к соседним значкам.

## 0.3.0

### Added

- Antigravity — лимиты на 5 часов и неделю для каждой группы моделей и ваш план, из приложения Antigravity, пока оно запущено. Без учётных данных и не дальше 127.0.0.1.
- Gemini CLI — токены, запросы и модели из его локальных записей сессий. Лимитов он не сообщает, поэтому они не показываются.
- Активность по моделям: список «Модели сегодня» для Codex, Claude Code и Gemini CLI, самые активные первыми.
- Планы Team: Claude показывает место, например Team · Premium; Codex — Team, Business и Enterprise.
- Режимы строки меню для Antigravity и Gemini CLI.
- Провайдеров можно упорядочить перетаскиванием в настройках; окно и виджет следуют этому порядку.
- Cursor и GitHub Copilot указаны как «скоро».

### Changed

- При трёх и более провайдерах средний виджет показывает по строке на каждого, а маленький — до трёх, ближайших к лимиту.
- Провайдер, добавленный в обновлении, один раз включается сам. Выключенные вами остаются выключенными.

### Fixed

- Лимиты Claude больше не просят пароль входа и возвращаются сами после запуска Claude Code.
- Окно лимита Claude, сбросившееся, пока вас не было, остаётся видимым, а исчерпанные лимиты показываются без всякого входа.
- Последние известные лимиты Claude переживают выход из приложения и его обновление.
